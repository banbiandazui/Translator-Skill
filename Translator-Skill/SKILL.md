# Translator Skill

## 功能

将用户输入文本转换为指定语言。

## 工作流程

1. 获取用户原始文本。
2. 判断目标语言。
3. 保持原文语义。
4. 调整表达符合目标语言习惯。
5. 输出翻译结果。

## 翻译原则

- 不改变原意。
- 保留专业词汇。
- 根据场景优化表达。
- 保持语言自然流畅。

## 输出内容

- 原文
- 目标语言
- 翻译结果
